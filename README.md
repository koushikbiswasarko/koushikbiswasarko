### Current research

| Focus | What it does |
| --- | --- |
| **Multi-class deepfake detection** | Leakage-controlled vision framework with residual attention. Identity- and video-level split protocol to avoid the data leakage that inflates much of this literature, evaluated with Grad-CAM, statistical testing, and external-domain generalization. |
| **Intelligent weed management** | Attention-enhanced YOLO for crop–weed detection, integrated end-to-end with an IoT mobile platform and robotic arm for targeted removal. |
| **Cardiovascular screening at the edge** | Attention-enhanced GRU for beat-to-beat ECG modelling on AD8232 + Raspberry Pi, benchmarked on latency, memory, power, and energy-per-inference for rural healthcare settings. |
| **Autonomous crop disease treatment** | A robot that navigates a strawberry field, localizes and classifies diseased plants, returns to a hub for the correct treatment, then navigates back for controlled spraying. |
